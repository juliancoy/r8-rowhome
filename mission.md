Design a row home model for the Baltimore R8 zoning category. We will be designing this row home using Typescript generators which render into Vulkan buffers and also are individually exportable to STL such that a model can be 3D printed. Be sure to implement all structural details according to best practices including facade, stairwell, fire escape, land around the building, we will be modeling, perhaps a tree, all the electrical, there will be no gas fitted in these houses. There will be a kitchen, oven, accessible 240 volt as well as the standard 120 volt according to electrical best practices which I hope you downloaded.

The model will be viewable in a web interface based on WebGPU. The user will be able to fly around it, scroll it, view the bill of materials, view the materials cost, and other aspects.
