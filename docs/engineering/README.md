# Engineering Process Index

This directory defines the engineering subprocesses used by the R8 Rowhome project. Each process document separates generated-model behavior from professional design work.

The current project is a source-traced conceptual model and browser viewer. It is not a permit set, sealed design package, construction document, or substitute for licensed Maryland professionals.

## Professionalization Rules

- Treat source code and deterministic tests as primary.
- Treat generated screenshots, benchmark bundles, and timestamped reports as artifacts.
- Do not claim code compliance from geometry alone.
- Keep warnings visible where professional design inputs are missing.
- Add a test before relying on any generated engineering behavior.
- Prefer structured metadata and source-traced assumptions over prose-only claims.
